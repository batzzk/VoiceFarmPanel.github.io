🎙️ VoiceFarmPanel

Plugin para farm de horas em call no Revenge.

VoiceFarmPanel

Painel flutuante com botão Ligar/Desligar. Entra na call uma única vez. Se for desconectado, não reconecta. Se for movido, fica no novo canal.

✅ Funcional
https://VoiceFarmPanel.github.io/

Instale no Revenge em: Plugins > Instalar > cole o link

📥 Como instalar

  1. Abra o Revenge (Discord modifica.do).
  2. Vá em Plugins.
  3. Toque no ícone de "+" ou "Install".
  4. Cole o link: https://VoiceFarmPanel.github.io/
  5. Clique em "Install".
  6. Ative o plugin na lista.
